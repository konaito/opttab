The problem

Your windows live in different Spaces.
Your switcher doesn't know that.

✕ Cmd+`

Cycles windows inside the current Space only. That second browser window on another desktop? Fullscreen terminal? Minimized editor? Invisible. You end up in Mission Control, hunting with the trackpad.

✓ OptTab

One keystroke reaches every real window of the active app — other Spaces, fullscreen, minimized. macOS jumps to the right Space for you. App-to-app switching stays where it belongs: Cmd+Tab.

Features

Small tool. Sharp edges filed off.

🪐

Crosses Spaces & fullscreen

Reaches windows on other desktops and fullscreen Spaces. For apps whose windows hide from the Accessibility API (hi, Chromium), it drives the app's own Window menu instead.

🖼️

Thumbnail HUD

Live window previews via ScreenCaptureKit, centered on the display your cursor is on. Never steals focus — the panel is non-activating by design.

🎯

Active app only

Deliberately scoped: OptTab cycles windows of the app you're in. ⌘Tab keeps switching apps. Two keystrokes, two clean jobs.

🧠

Knows tabs aren't windows

Native-tab apps (Ghostty, Terminal…) leak background tabs into the window list. OptTab filters out anything you can't actually switch to.

🔓

Public APIs only

No private CGS calls, no injected code. CGEventTap + ScreenCaptureKit + Accessibility. Survives macOS updates like a good citizen.

🕯️

Degrades gracefully

No screen-recording permission? It still works — app-icon cards instead of thumbnails. Accessibility granted late? It picks itself up automatically.

Under the hood

Four public APIs in a trench coat

Everything is boring, documented macOS API — arranged in a fallback chain so the switch lands even when an app hides its windows.

CGEventTap ──▶ capture ⌥⇥ before the app sees it ──▶ swallow · cycle · commit on ⌥ release
ScreenCaptureKit ──▶ enumerate windows (onScreenWindowsOnly: false → every Space) + thumbnails
Accessibility ──▶ match CG ↔ AX windows ──▶ AXRaise the winner
└─ no AX handle? (other-Space Chromium…) ──▶ press its Window-menu item — jumps Spaces via public AX
Install

Brew, copy, switch.

ghostty — zsh 
$ brew install --cask konaito/tap/opttab   # notarized — no build needed
$ open /Applications/OptTab.app

# or build from source:
$ brew install konaito/tap/opttab
$ git clone https://github.com/konaito/opttab.git && cd opttab && ./Scripts/bundle.sh
⚠️ First launch asks for Accessibility (the hotkey) and Screen Recording (thumbnails — optional, icon cards otherwise). OptTab lives in your menu bar; enable "Launch at Login" from there.
